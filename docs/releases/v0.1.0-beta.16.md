# AYTHER Runtime v0.1.0-beta.16

This beta updates the locked AYTHER Engine dependency to `v0.1.0-rc.24` (and
`native-v0.1.0-rc.24` for the Tessera MVP route).

- Fixes `AytherSession::reset()` when running with the native Tessera provider
  so observer subscriptions (VRAM/CRAM/VSRAM/SAT) remain attached after a
  session reset.
- Moves the release and QA Engine locks (`dependencies/ayther-engine.lock.json`
  and `dependencies/ayther-engine.qa.lock.json`) to `v0.1.0-rc.24`, and
  `dependencies/ayther-engine.native-mvp.lock.json` to `native-v0.1.0-rc.24`.
- Runtime–Play protocol v1 and the supported Engine package range
  `>=0.1.0,<0.2.0` remain unchanged.

See [Runtime–Engine compatibility](../runtime-engine-compatibility.md) and the
[changelog](../../CHANGELOG.md).
