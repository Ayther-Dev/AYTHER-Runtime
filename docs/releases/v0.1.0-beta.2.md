# AYTHER Runtime v0.1.0-beta.2

This is the second reproducible internal beta of AYTHER Runtime. It adds the
Runtime side of AYTHER Play's per-session control mapping while preserving the
protocol-v1 and package contracts introduced in `v0.1.0-beta.1`.

## Highlights

- New `--input-map <controls.toml>` option for keyboard and gamepad RetroPad
  bindings generated by AYTHER Play.
- Startup-only TOML parsing into resolved SDL enums; the frame loop performs no
  mapping string parsing.
- Partial maps inherit Runtime defaults, while unknown sections, actions,
  values and duplicate effective bindings fail deterministically.
- Invalid maps are rejected before SDL initialization with process exit code
  `78`, stable reason `input.map_invalid`, and a human-readable diagnostic.
- Gamepad face buttons use layout-independent physical positions
  (`south`, `east`, `west`, `north`); D-pad and left-stick directions remain
  fixed and are combined with mapped inputs.

## Compatibility

- Runtime–Play process protocol v1 remains stable.
- The supported installed AYTHER Engine range remains `>=0.1.0,<0.2.0`.
- Reproducible packages remain locked to AYTHER Engine `v0.1.0-rc.6`.
- Launches without `--input-map` retain the `v0.1.0-beta.1` default controls,
  including the legacy `Backspace` alias for Select.

## Verification

The release workflow rebuilds and tests the tagged source independently on
Windows 11/MSVC v145 and Ubuntu 24.04/Clang 18 before producing the Windows ZIP
and Linux TGZ archives. Each archive is accompanied by a platform-specific
SHA-256 checksum file.

## Known limitations

- Libretro cores execute as native code and are not sandboxed.
- Runtime/Engine ABI, package, configuration and save-state compatibility may
  change before the stable release.
- There is no graphical installer or automatic updater in this beta.
- Third-party license inventory and signed release provenance remain stable
  release gates.
