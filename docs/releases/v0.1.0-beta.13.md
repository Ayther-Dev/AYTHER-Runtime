# AYTHER Runtime v0.1.0-beta.13

This beta moves the reproducible Runtime dependency to AYTHER Engine
`v0.1.0-rc.19`, whose HD music follows the game when it restarts the same
music, and completes pad timelines that start from a Lab bookmark (spec 006).

- With Engine `v0.1.0-rc.19`, Golden Axe's "The Battle" intro restarts in HD
  when the selection screen restarts it, instead of the title's HD intro
  running out and the original sound playing until the loop.
- A timeline that starts from a Lab bookmark seeds the detector with the
  bookmark's `.fm` sidecar (the detector's FM register shadow the Lab saves next
  to the `.sav`), so music that was already playing identifies its
  instruments. `timeline_compiled` reports `fm_seeded`; a sidecar that is not
  512 bytes ends the run with `timeline_fm_sidecar_invalid`.
- `ayther_audio_qa check` reports `audio_qa_warning: timeline_fm_seed_absent`
  when a timeline started from a bookmark without a seeded shadow; before, the
  warning never reached the report.
- The release and QA Engine locks move from `v0.1.0-rc.18` to the published
  `v0.1.0-rc.19`; the bootstraps verify its SHA-256, the release checksums and
  its SLSA provenance. Runtime–Play protocol v1 and the supported Engine
  package range `>=0.1.0,<0.2.0` remain unchanged.

See [Runtime–Engine compatibility](../runtime-engine-compatibility.md) and the
[changelog](../../CHANGELOG.md).
