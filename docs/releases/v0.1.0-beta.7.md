# AYTHER Runtime v0.1.0-beta.7

This beta moves the Engine lock from `v0.1.0-rc.9` to `v0.1.0-rc.10`, which
teaches the pose matcher the RELATIVE flip of each member sprite.

- Two poses that differ only in the flip of one member are now told apart. In
  Golden Axe the dwarf stands with his head facing his body or facing away:
  the same three sprites at the same offsets, with only the head flipped. Until
  now the per-member flips in the pack were only a tiebreak, so the two
  variants could not be authored separately and a tween between them never
  fired. When both variants match the same sprites, the one whose flips agree
  wins; a whole-pose mirror is still the same pose.
- In a left-right symmetric layout the matcher no longer drops the mirror
  arrangement by position alone: a mirrored instance resolves to the right
  variant and its HD is drawn mirrored. An HD authored facing the other way in
  such a pose shows inverted; the author fixes it with the asset's flip.
- Packs already carried the per-member `flips`, so every existing pack plays
  as before except in those cases; no re-export is needed.
- The lock carries the four rc.10 archives with their published SHA-256
  values, the checksum-file hash and the SLSA source ref; CMake, the CI
  bootstrap gate, the contract tests and the documentation follow the lock.
- The Engine package version stays `0.1.0`, so the supported range
  `>=0.1.0,<0.2.0` and the Runtime-Play protocol v1 are unchanged, and the C
  ABI revision stays at 7. The rc.6 reload-path workaround is kept.
- No Runtime feature or wire-protocol change. The optional Play file
  reservations, `--trust-registry`, the fatal pack diagnostics and the exit
  codes are those of beta.6.

See [Runtime-Engine compatibility](../runtime-engine-compatibility.md) and
