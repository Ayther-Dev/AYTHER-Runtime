# AYTHER Runtime v0.1.0-beta.6

Play CE puede solicitar ahora la reserva de ROM y pack mediante --rom-revision y --pack-revision. Runtime comprueba los tokens y confirma AYTHER_RESERVATION 1 antes de continuar. Esto permite transferir las reservas del launcher al proceso de sesión sin aceptar una revisión diferente del archivo.

En Windows, la reserva permanece durante la sesión e impide escritura, borrado y renombrado. Una revisión distinta o un archivo inaccesible impiden confirmar el intercambio. Las plataformas sin soporte rechazan solicitudes explícitas; el lanzamiento sin estas opciones mantiene las validaciones anteriores.

Engine permanece en v0.1.0-rc.9, paquete 0.1.0 y ABI C del core 7. Windows consume engine-vpx con SHA-256 2d70dc74f4de5db4a21e71185eab12ca2aebea533f53fb21d5d9a710e13d1f2d. El protocolo de estado Runtime–Play continúa en v1; la línea de confirmación de reservas es adicional y optativa.

La release incluye pruebas nativas de reserva y liberación, rechazo de revisiones y regresión del lanzamiento sin reservas. El proceso de publicación ejecuta la suite de cada plataforma. El intercambio con tokens generados por Play CE se valida además contra el ejecutable Windows distribuido.

Alcance: compatibilidad de lanzamiento. No contiene correcciones de audio, cambios de Engine, replay de tomas ni instrumentación de QA. Contrato: [reservas](../specs/runtime-reservations.md).
