# AYTHER Runtime v0.1.0-beta.3

This beta connects Runtime to Engine rc.6's production trust registry and makes
an explicitly requested pack mandatory for a successful session.

- Added `--trust-registry <file.toml>` with early path resolution and configuration
  diagnostics. Engine verifies signatures, validity, revocation and game scope.
- Kept the registry across hot reloads, with a Runtime workaround for rc.6's
  internal pack-path aliasing during reload.
- Added fatal `pack.open_failed` (exit 4) and `pack.trust_registry_invalid` (exit 78).
  A failed explicit pack can no longer report success by playing the original ROM.
- Added signed, unknown-key, revoked, expired, future, wrong-game, tampered,
  unsigned and development-key fixtures, plus session and CLI regression tests.
- Windows packages use the checksum-pinned Engine rc.6 VPX variant for VP9.
  Linux retains the non-VPX variant. Protocol v1 is unchanged.

See [trust registry configuration](../trust-registry.md) and
[Windows acceptance evidence](../validation-beta.3.md).

Windows validation: 50/50 CTests passed; the trust tests also passed in explicit
Release configuration. Installed-package Golden Axe playback completed 600
frames with `has_pack=1` and exit 0. The test-signed VP9 variant also completed
600 frames and delivered 57 decoded video frames. The original input pack was
preserved; the signed acceptance copies use test-only keys.

The release publishes Windows ZIP and Linux TGZ archives with platform SHA-256
checksum files. `v0.1.0-beta.2` remains available unchanged as historical reference.
Test keys, ROMs, cores and local acceptance packs are not bundled in the release.
