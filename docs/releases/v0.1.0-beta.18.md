# AYTHER Runtime v0.1.0-beta.18

This beta updates the locked AYTHER Engine dependency to `v0.1.0-rc.28` and lets
the launcher customise the pause dialog.

- Moves the release and QA Engine locks (`dependencies/ayther-engine.lock.json`
  and `dependencies/ayther-engine.qa.lock.json`) to `v0.1.0-rc.28`, and
  `dependencies/ayther-engine.native-mvp.lock.json` to `native-v0.1.0-rc.28`
  (same Engine commit, `6d1c2e8`).
- New pause-dialog options:
  - `--accent-color <#RRGGBB>`: accent of the dialog (caption, primary button,
    checkboxes, sliders and hover states). Default `#FB2C36`. The label of the
    primary button switches between dark and white text for contrast.
  - `--title <text>`: caption above «EN PAUSA». Default `Runtime` (it used to be
    the fixed `AYTHER PLAY CE`).
  - `--exit-button-text <text>`: label of the button that closes the Runtime.
    Default `Salir` (it used to be `Volver al launcher`).

  A malformed colour is `args.value_out_of_domain` and an empty value is
  `args.empty_value` (exit 64).
- Frame pacing follows `timing_fps()` when the core only reports its rate after
  the first frame (Tessera ran at 20 Hz), and the dev options `--input-script`
  and `--frame-log` time a game reproducibly.
- Runtime–Play protocol v1 and the supported Engine package range
  `>=0.1.0,<0.2.0` remain unchanged.

See [Runtime–Engine compatibility](../runtime-engine-compatibility.md) and the
[changelog](../../CHANGELOG.md).
