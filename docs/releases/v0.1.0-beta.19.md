# AYTHER Runtime v0.1.0-beta.19

This beta ships the Tessera native provider in the Windows Runtime and hardens
the command line.

- The Windows archive is built against the native Engine package
  `native-v0.1.0-rc.28` and Tessera `v0.2.0-rc.9`, so `--provider tessera`
  (AYTHER's own Mega Drive core) works in the released Runtime. Both are static
  libraries; the archive adds no DLL. Configuration fails without the provider
  (`AYTHER_REQUIRE_TESSERA_PROVIDER=ON`), and `tools/bootstrap_tessera.ps1`
  downloads and verifies the locked Tessera package. The Linux archive is
  unchanged and has no Tessera provider.
- The archives carry the Engine licenses and, on Windows, the Tessera licenses,
  notices and source-availability statement under `share/licenses/`.
  `ayther-runtime-package.json` records `tessera_provider` and
  `tessera_version`.
- The default pause-dialog accent (`--accent-color`) is `#FF7300`.
- An unknown `--` option is rejected with `cli.invalid_argument` (exit 64)
  instead of being read as a core or ROM path.
- New AYTHER Runtime logo and Windows executable icon.
- Runtime–Play protocol v1 and the supported Engine package range
  `>=0.1.0,<0.2.0` remain unchanged. The Tessera integration tests still run
  only locally.

See [Runtime–Engine compatibility](../runtime-engine-compatibility.md) and the
[changelog](../../CHANGELOG.md).
