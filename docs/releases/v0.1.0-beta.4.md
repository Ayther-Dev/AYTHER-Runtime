# AYTHER Runtime v0.1.0-beta.4

This beta moves the Engine lock from `v0.1.0-rc.6` to `v0.1.0-rc.8` so that
packs play with the two Engine fix-forwards published since beta.3.

- Plane sets are tried by complexity: a larger multi-tile element keeps its HD
  replacement when the one-tile elements it contains receive an asset (rc.8;
  Golden Axe, "Ax Battler - Magic bar" over "Magic bar - Empty/Border").
- A 1x1 plane sub under a glyph no longer claims the cell of another plane, so
  the original behind HD text is drawn again (rc.7).
- The lock carries the four rc.8 archives with their published SHA-256 values,
  the checksum-file hash and the SLSA source ref; CMake, the CI bootstrap gate,
  the contract tests and the documentation follow the lock.
- The Engine package version stays `0.1.0`, so the supported range
  `>=0.1.0,<0.2.0` and the Runtime–Play protocol v1 are unchanged. The rc.6
  reload-path workaround is kept; the Engine changelog records no fix for it.
- No Runtime feature or wire-protocol change. `--trust-registry`, the fatal
  pack diagnostics and the exit codes are those of beta.3.

See [Runtime–Engine compatibility](../runtime-engine-compatibility.md) and
[status](../status.md).

Windows validation (2026-09-12): the bootstrap downloaded and verified both
Windows archives (`engine` and `engine-vpx`) against the lock, the published
checksums and SLSA provenance; the `windows-ci` preset (Visual Studio 2026,
MSVC 19.51.36256.0, toolset v145 14.51.36231) passed the toolchain, package and
link contracts against the `engine-vpx` prefix, built RelWithDebInfo and passed
50/50 CTests. The pull request CI repeated the Windows and Linux builds, the
ASan/UBSan/fuzz job and the security scans on the same commit.

The release publishes Windows ZIP and Linux TGZ archives with platform SHA-256
checksum files. Windows packages use the locked Engine rc.8 VPX variant for
VP9; Linux retains the non-VPX variant. `v0.1.0-beta.3` remains available
unchanged as historical reference. Test keys, ROMs, cores and local acceptance
packs are not bundled in the release.
