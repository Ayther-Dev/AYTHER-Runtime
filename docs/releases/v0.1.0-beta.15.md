# AYTHER Runtime v0.1.0-beta.15

This beta moves the reproducible Runtime dependency to AYTHER Engine
`v0.1.0-rc.23` and adds the emulation-provider choice of spec 008: the same
Runtime runs a game with the external libretro core or with Tessera.

- `--provider external|tessera`. With `tessera` the game runs through
  `AytherSession` on the Engine's native `megadrive` machine, without `--core`;
  live input, the overlay, shaders, `hd_compose`, capture and packs work as with
  the external core, and a pack baked with gpgx plays under Tessera. `--core`
  together with `--provider tessera` is `args.provider_conflict` (exit 64).
- Save states record the emulator generation (`SaveStateStore` v2). A state
  from another generation is refused with exit 65; a state without the header
  counts as gpgx.
- `--probe-core` answers the Engine's probe contract v2 (exit 0, 2, 3 or 4).
- The release and QA Engine locks move from `v0.1.0-rc.22` to the published
  `v0.1.0-rc.23` (core C ABI revision 9). The regular rc.23 package does not
  carry the native provider: the Tessera route is built against the Engine-only
  `native-v0.1.0-rc.23` package, pinned by
  `dependencies/ayther-engine.native-mvp.lock.json`, and Tessera `v0.2.0-rc.9`.
  The route stays off by default and is not part of the release archive's default
  build. Runtime–Play protocol v1 and the supported Engine package range
  `>=0.1.0,<0.2.0` remain unchanged.

See [Runtime–Engine compatibility](../runtime-engine-compatibility.md) and the
[changelog](../../CHANGELOG.md).
