# AYTHER Runtime v0.1.0-beta.17

This beta updates the locked AYTHER Engine dependency to `v0.1.0-rc.25` (and
`native-v0.1.0-rc.25` for the Tessera MVP route).

- Initializes pack consumers (`tile_sub`, `plane_sub`, `sprite_sub`, `pose_sub`,
  `tween`, `audio_sub`) on packless `tessera_native` sessions by invoking
  `set_pack("")`, matching the libretro open path.
- Moves the release and QA Engine locks (`dependencies/ayther-engine.lock.json`
  and `dependencies/ayther-engine.qa.lock.json`) to `v0.1.0-rc.25`, and
  `dependencies/ayther-engine.native-mvp.lock.json` to `native-v0.1.0-rc.25`.
- Runtime–Play protocol v1 and the supported Engine package range
  `>=0.1.0,<0.2.0` remain unchanged.

See [Runtime–Engine compatibility](../runtime-engine-compatibility.md) and the
[changelog](../../CHANGELOG.md).
