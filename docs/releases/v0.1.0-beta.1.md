# AYTHER Runtime v0.1.0-beta.1

This is the first reproducible internal beta of AYTHER Runtime. It is intended
for engineering integration and evaluation with AYTHER Play; it is not a
production or generally available release.

## Highlights

- Stable Runtime–Play protocol v1 with negotiation, typed errors and fixed
  process exit codes.
- Transactional configuration, save states and synchronized captures.
- Transactional Vulkan presentation lifetime with failure injection and a real
  validation-layer GPU smoke.
- Strict compiler warnings, clang-tidy, ASan/UBSan, deterministic fuzzing and a
  60% coverage gate for CPU-owned parser, protocol and persistence code.
- Relocatable Windows ZIP and Linux TGZ packages produced from CMake install
  rules and verified from an empty working directory.
- AYTHER Engine `v0.1.0-rc.6` locked by artifact checksum and SLSA provenance.

## Supported evaluation environments

- Windows 11 x86-64 with the MSVC v145 ABI/toolset and Vulkan 1.1 or newer.
- Ubuntu 24.04 x86-64 with Clang 18, libstdc++ and Vulkan 1.1 or newer.

Only the NVIDIA RTX 3060 Laptop GPU row has completed the real validation-layer
presentation smoke. Integrated GPUs, other discrete GPUs and real third-party
Libretro cores remain compatibility candidates rather than support claims.

## Verification

Each archive is built from the release tag after the complete CTest suite. The
release also includes platform-specific `SHA256SUMS` files. Compare the digest
of the downloaded archive before extracting it.

## Known limitations

- Libretro cores execute as native code and are not sandboxed.
- Runtime/Engine ABI, package, configuration and save-state compatibility may
  change before the stable release.
- There is no graphical installer or automatic updater in this beta.
- Third-party license inventory and signed release provenance remain stable
  release gates.
