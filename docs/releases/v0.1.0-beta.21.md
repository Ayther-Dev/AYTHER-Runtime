# AYTHER Runtime v0.1.0-beta.21

This beta changes only how the Runtime is published; the executable behaves as
in beta.20.

- Releases are not code-signed. The SignPath Foundation signing request was
  rejected, so the release workflow has no signing step. Windows SmartScreen
  may warn on first run: verify each archive against its `SHA256SUMS-*.txt`
  file.
- `LICENSE` is the unmodified MPL-2.0 text; the project notice on what it
  covers is in `NOTICE.md`, installed next to it in
  `share/licenses/ayther-runtime`.
- The Windows archive still includes the Tessera provider (`native-v0.1.0-rc.28`
  and Tessera `v0.2.0-rc.9`). Runtime–Play protocol v1 and the supported Engine
  package range `>=0.1.0,<0.2.0` remain unchanged.

See [Runtime–Engine compatibility](../runtime-engine-compatibility.md) and the
[changelog](../../CHANGELOG.md).
