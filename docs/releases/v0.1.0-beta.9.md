# AYTHER Runtime v0.1.0-beta.9

This beta adds replay inspection and the replay QA tools of spec 002, and
updates the reproducible Runtime dependency to AYTHER Engine `v0.1.0-rc.15`.

- The visible replay can be paused and resumed with Space, stepped one frame
  forward or back while paused, and inspected with the debug overlay; every
  visit is recorded as evidence.
- A pause requested while no frame is in progress keeps the frame on screen
  (RF-4.1); after the last frame of an intermediate take, the next take starts
  on the next cadence slot, so a pause there keeps the take on its last frame
  (RF-2.8).
- The replay QA launcher `ayther_replay_qa` and the `ayther_audio_qa check`
  runner ship in the `qa` component of QA builds; the release packages contain
  the Runtime component only.
- The release and QA Engine locks pin `v0.1.0-rc.15`; the QA bootstrap
  downloads the published `engine-vpx` artifact and verifies its SHA-256, the
  release checksums and its SLSA provenance.
- Pull requests to `main` now require the `Windows / QA` check.
- Runtime–Play protocol v1 and the supported Engine package range
  `>=0.1.0,<0.2.0` remain unchanged.

See [Runtime–Engine compatibility](../runtime-engine-compatibility.md) and the
[changelog](../../CHANGELOG.md).
