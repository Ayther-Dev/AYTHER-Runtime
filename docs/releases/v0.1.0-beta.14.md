# AYTHER Runtime v0.1.0-beta.14

This beta moves the reproducible Runtime dependency to AYTHER Engine
`v0.1.0-rc.22`, publishes the emulator generation of the session in the
`ready` status record (spec 008), and adds an optional native Tessera route.

- The release and QA Engine locks move from `v0.1.0-rc.19` to the published
  `v0.1.0-rc.22` (core C ABI revision 9); the bootstraps verify its SHA-256,
  the release checksums and its SLSA provenance. The Engine take format is
  `.arp` v11, which older readers cannot open, and `AytherRecording::abi_size()`
  changes with it, so a consumer must be built against the headers of the
  locked Engine. Runtime–Play protocol v1 and the supported Engine package range
  `>=0.1.0,<0.2.0` remain unchanged.
- The `ready` status record carries `emulator_id`, `emulator_version` and
  `determinism_contract` when the Engine reports an emulator generation. The
  fields are additive within protocol v1 and absent otherwise.
- An optional native Tessera route (`AYTHER_ENABLE_TESSERA_NATIVE`, Windows x64)
  presents native frames and audio through the Runtime Vulkan path. It is off by
  default and is not part of the release archive's default build. Its
  integration tests need local fixtures and a GPU and were not run for this
  release.

See [Runtime–Engine compatibility](../runtime-engine-compatibility.md) and the
[changelog](../../CHANGELOG.md).
