# AYTHER Runtime v0.1.0-beta.20

This beta lets the launcher choose the label colour of the pause dialog's
accent-filled buttons.

- New option `--accent-text <#RRGGBB>`: colour of the label on accent-filled
  buttons (the primary «Continuar» button). Default `#FFFFFF`. It replaces the
  automatic choice between dark and white text, which put dark text on
  `#FB2C36`. It accepts the same spelling as `--accent-color`; anything else is
  `args.value_out_of_domain` (exit 64).
- The Windows archive still includes the Tessera provider (`native-v0.1.0-rc.28`
  and Tessera `v0.2.0-rc.9`). Runtime–Play protocol v1 and the supported Engine
  package range `>=0.1.0,<0.2.0` remain unchanged.

See [Runtime–Engine compatibility](../runtime-engine-compatibility.md) and the
[changelog](../../CHANGELOG.md).
